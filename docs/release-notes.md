Scopelet 0.1.0: a Rust CLI and installable skill for composing local evidence queries.

- Repository text, JSON/JSONL, command capture and optional codeindex/webindex adapters.
- Default and opt-in ultra views, immutable original recovery and explicit coverage.
- Offline correctness checks and reproducible real Codex/Claude Code evaluation harness.

Install: `npx skills add maxgfr/scopelet -a codex claude-code`.
See the README and published verification report for tested versions, measurements and limits.
